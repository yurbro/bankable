Workflow: numbers before narrative

Eight steps, each loading only the reference it needs. The financial model runs first; the narrative may quote only numbers the model produced.

0

Take stock

Read every input; fix the primary reader, stage, deliverables and tooling

1

Interview

One round, max 8 questions, only what the inputs lack; absent user → defensible assumptions

2

Register

F facts / A assumptions / E inferences / T to-provide, with source, evidence grade, confidence, confirm flag

3

Research

Official statistics, policy texts, comparable filings; bottom-up market sizing; sources tagged [S-n]

4

Model

assumptions.json → Excel 3 statements → LibreOffice recalc → 3 scenarios + sensitivity → model_outputs.json

5

Draft

15 chapters weighted by reader; claims tagged [A-xx][S-n]; figures only from model output

6

Check & review

Script checks narrative vs model; red-team questions from investor / credit / government / CFO; review memo

7

Deliver

Word (zh/en), Excel, PPT, register + delivery note: assumptions to confirm, gaps, model conclusions, limits

Iterate: a chapter reveals a constraint (capacity, payment terms, permits) → change the assumption → rerun step 4 → update the text
Never hand-edit outputs
No fabricationCompany history, customers, contracts, licences and team bios come only from the user's material — otherwise [to be provided]; market and policy data need a source or are marked [to verify].
Numbers reconcileThe balance sheet balances by construction; every financial figure in the text equals the model output; check_consistency.py catches "forecast" numbers the model never produced.
Reader-awareOne model, different metrics: investors see CAGR / IRR, banks DSCR / downside, government reviewers benefit and performance indicators, boards NPV / alternatives.
