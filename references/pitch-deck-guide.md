# 路演 PPT 指南

PPT 是计划书的提炼，不是复制。原则：一页一个信息，数字大字号，每页注明数据来源（"财务模型 基准情景""[S2]"），讲稿放在备注。先写 `work/deck.md`（格式见 `scripts/build_pptx.py` 顶部），再制作。

制作方式：环境里有 pptx skill（Anthropic 的 PowerPoint 技能）时优先用它做版式更好的版本——把 deck.md 作为内容大纲交给它，并要求使用 `charts/` 下的图；没有时用 `scripts/build_pptx.py`。

## 投资人版（12–15 页）

| 页 | 标题思路 | 内容来源 |
|---|---|---|
| 1 | 封面：项目名 + 一句话定位 | 执行摘要首段 |
| 2 | 问题：谁、什么痛点、多大损失 | 第 3 章痛点，数据 [S] |
| 3 | 方案：产品/服务 + 为什么更好 | 第 3 章 |
| 4 | 为什么是现在：政策/技术/需求拐点 | 第 4 章宏观 |
| 5 | 市场：TAM/SAM/SOM 漏斗与算法 | 第 4 章测算 |
| 6 | 商业模式与单位经济 | 第 6 章 |
| 7 | 进展（traction）：收入/客户/合同/试点 | 第 2、4 章证据 |
| 8 | 竞争：对比矩阵 + 壁垒 | 第 5 章 |
| 9 | 增长策略：渠道、里程碑 | 第 7、10 章 |

## 银行版（10–12 页）

封面 → 借款人概况与资质 → 项目概况与用途 → 市场与订单支撑 → 投资与资金筹措 → 还款来源：经营现金流与 DSCR（`charts/dscr.png`）→ 月度/年度现金流（`charts/cash_balance.png`、`charts/monthly_cash.png`）→ 保守情景偿债能力 → 担保措施 → 风险与应对 → 贷款申请要素汇总。

## 政府 / 园区版（12–15 页）

封面 → 政策依据与项目定位 → 申报主体与基础 → 建设内容与规模 → 技术方案与创新性 → 总投资与资金筹措（含配套）→ 实施进度 → 经济效益（产值、税收、利润）→ 社会与环境效益（就业、带动、绿色指标）→ 绩效目标 → 组织保障与风险 → 申请事项。

## 内部 / 董事会版（8–10 页）

决策请求（一页讲清批准什么）→ 背景与战略契合 → 方案比较（含不做）→ 资源需求与预算 → 财务评价（NPV/IRR/回收期、敏感性）→ 里程碑与决策点 → 风险与止损条件 → 负责人与治理 → 请求批准事项。

## 每页写法

- 标题写结论（"五年收入 CAGR 28%，第二年盈利"），不写话题（"财务预测"）；标题不超过 30 字。
- 正文 3–5 个要点，**每点一行、不超过 30 字**；细节放备注或附录页。试跑中最常见的失败是把正文段落搬上幻灯片——一页十条长句评审不会读。要点超过 8 条时 `build_pptx.py` 会提示拆页。
- 数字型内容用表（deck.md 里直接写 Markdown 表格，脚本会转成 PPT 表格）或图，不要用要点列数字。
- 图优先用计划书里已生成的图表，保证口径一致。
- 备注写 30–60 秒讲稿，并注明预期被问到的问题与回答要点。
- 对外版本脱敏：客户实名、合同金额、未公开财务数据。
