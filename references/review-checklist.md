# 评审清单：红队提问、一致性检查、写作质量

用法：初稿完成并跑过 `check_consistency.py` 后，按主读者挑对应的提问清单（次要读者各挑 3–5 条），加上一致性与写作清单，写一份评审备忘（模板 `assets/review-memo-template.md`），逐条修订。严重度分三级：**致命**（评审会直接否决）、**重要**（会被追问、影响可信度）、**一般**（打磨）。

## 一、红队提问

### 投资人（投委会口吻）

1. 这个市场的 SAM 是怎么算出来的？每个因子的来源？如果渗透率假设减半，SOM 变成多少？
2. 为什么客户现在不用现有方案解决这个问题？你的方案贵还是便宜、快还是慢？
3. 第 3 年的收入靠多少客户、多少单、多大客单价？销售团队产能支撑得了吗？
4. 单位经济：一个客户的获客成本、毛利、回本周期、生命周期价值分别多少？数据来自哪里？
5. 毛利率为什么能比行业头部高/为什么会逐年提升？
6. 最大的三个竞争对手看到你做这件事会怎么反应？你的壁垒多久会被追平？
7. 本轮资金能支撑多久？花完时达到什么里程碑，下一轮凭什么能融到？
8. 估值的依据是什么？可比交易或倍数在哪里？
9. 团队里谁做过这件事？缺谁？
10. 如果第 1 年销量只有计划的一半，你会怎么做？什么指标出现时你会调整？
11. 收入确认、退货/退款、渠道压货有没有被忽略？
12. 资金用途里"运营资金"具体是什么？

### 银行 / 信贷审查

1. 还款来源是什么？贷款期内每年的经营现金流能覆盖本息几倍？最低的一年是哪年？
2. 销量下降 20% 还能还得上吗？价格下降 10% 呢？
3. 历史财务报表与纳税申报一致吗？（有历史的企业）
4. 贷款用途具体买什么、什么时候付款、与项目进度对得上吗？
5. 抵押物是什么、评估值多少、是否已抵押给他人？保证人资质？
6. 现有负债与授信情况？资产负债率会升到多少？
7. 应收账款账期多长、客户集中度多高、有无坏账历史？
8. 项目需要哪些许可、环评、用地手续？目前状态？
9. 股东实缴资本是否到位？自有资金比例够不够（通常项目贷款要求 ≥ 20–30%）？
10. 如果项目延期半年，利息和现金流怎么安排？
11. 关键人风险：核心负责人离开会怎样？
12. 行业周期现在处于什么位置？

### 政府评审 / 园区招商

1. 项目对应哪项政策、哪个产业目录条目？与地方产业规划是什么关系？
2. 申报主体是否符合资格条件（注册地、成立年限、资质、信用）？
3. 总投资的构成与依据？资金来源能否落实？自筹部分的证明？配套比例是否满足要求？
4. 技术路线的先进性对比谁？有没有知识产权、标准、认证？
5. 达产后产值、税收、就业各多少？怎么算的？投资强度与亩均税收是否达标？
6. 建设周期是否可行？用地、环评、能评、安评等前置条件的状态？
7. 绩效目标是否可考核？年度指标是什么？
8. 对本地产业链、就业、乡村振兴、绿色低碳的量化贡献？
9. 项目失败或延期的风险与保障措施？
10. 资金使用计划与财务管理制度？
11. 有没有同类项目在其他地区的运行数据？
12. 社会稳定、环境影响、安全生产方面有没有敏感点？

### CFO / 董事会 / 合作伙伴

1. 请董事会批准的具体是什么？金额、期限、授权范围？
2. 备选方案是什么？为什么不是延后或缩小规模？
3. 峰值资金占用多少、什么时候？对公司现金和现有业务的影响？
4. NPV/IRR 对哪三个假设最敏感？±20% 的结果？
5. 负责人是谁？里程碑与决策点是什么？什么情况下止损？
6. 需要从现有业务抽调哪些资源？机会成本是什么？
7. 与公司战略的契合点在哪？不做会怎样？
8. 合作方案中各方投入、分成、排他、知识产权、退出条款是否清楚？
9. 财务口径与公司管理报表一致吗？
10. 风险登记与应对的责任人是谁？

## 二、一致性检查

- [ ] 同一指标在执行摘要、正文、表格、附录中的数字一致（跑 `check_consistency.py`）。
- [ ] 收入线、费用线、人员、资本开支与运营/营销/团队章节的描述一一对应（产品清单 = 收入线；设备清单 = capex；人员计划 = headcount）。
- [ ] 融资/申请金额 = 模型中的股权 + 借款；资金用途合计 = 融资金额；用途与投资计划对应。
- [ ] 里程碑时间与资金到位、投产、达产年份一致。
- [ ] 市场份额 = 模型收入 / 市场规模，与市场章节的 SOM 一致。
- [ ] 风险矩阵中的风险与下行情景的驱动因素对应。
- [ ] 日期、公司名、项目名、单位、口径（含税/不含税）全篇统一。
- [ ] 每个 `[S*]` 都在来源清单里；每个 `[A-*]` 都在登记册里。
- [ ] 政府版：总投资、资金筹措表、效益指标表三者互相对得上。

## 三、写作质量

- [ ] 执行摘要 ≤ 2 页，首段回答主读者的第一个问题。
- [ ] 没有无依据的最高级与形容词（"领先""顶尖""巨大"）。
- [ ] 没有模板句（"随着经济的发展……""市场前景广阔"）。
- [ ] 每个章节以结论开头，再给证据；段落不超过 6 行。
- [ ] 表格有表题与单位，图有图题与来源。
- [ ] 风险章节有具体触发指标和责任人。
- [ ] `[待补充]` 项集中列在交付说明里，正文中不超过评审能接受的数量（通常 ≤ 10 处）。
- [ ] 对外版本已脱敏（客户实名、合同金额、未公开数据）。

## 四、诚信底线

- [ ] 没有编造的历史、客户、合同、资质、团队背景。
- [ ] 预测没有被"倒推"去凑融资额或估值；模型假设有来源。
- [ ] 政策引用有文件名、文号或条款；没有过期或已废止的政策。
- [ ] 免责声明与保密声明在位。

## 评审备忘输出

按 `assets/review-memo-template.md` 列出：编号（Q-xx；风险矩阵用 R-xx，登记册用 F/A/E/T，不要混用）、来源（哪位读者/哪条清单）、问题、严重度、建议修改、涉及章节/模型字段、状态。修订后在备忘里标"已处理"或"交付说明中披露"，连同交付物一起给用户。
