# 读者画像：谁在看、怎么看、为什么毙

同一个项目给四类读者看，章节几乎一样，但权重、顺序、指标和语气完全不同。写之前先确定主读者，然后按这里的权重决定每章篇幅。

## 1. 股权投资人（VC / 天使 / 产业资本）

**他们怎么读**：先看执行摘要和团队，再看市场和商业模式，财务只看增长、毛利、单位经济和资金用途。决策依据是"回报倍数 × 概率"，所以他们要的是**为什么这个市场够大、为什么你能赢、为什么是现在**。

**评审关注点**（按重要性）：
1. 市场：TAM/SAM/SOM 有自下而上测算；增长驱动是结构性的（政策、技术、需求变化），不是"市场很大"。
2. 产品与壁垒：解决什么痛点、为什么现有方案不行、壁垒是技术/数据/渠道/成本/牌照中的哪一种，以及壁垒多久会被追上。
3. 商业模式与单位经济：客单价、毛利率、获客成本（CAC）、回本周期、客户生命周期价值（LTV）、复购或留存。早期项目至少要有单位经济的逻辑和首批验证数据。
4. 进展（traction）：收入、客户、合同、试点、增长率——这是最有说服力的部分，有多少写多少，没有就老实写里程碑计划。
5. 团队：为什么这个团队能做成这件事（行业经验、技术积累、过往业绩）；关键空缺与补齐计划。
6. 融资方案：金额、用途（分项百分比）、能撑多久（runway）、达成什么里程碑后进入下一轮、估值逻辑（可比交易、收入倍数），退出路径。
7. 风险：诚实列出，加应对。

**必须有的内容**：市场测算过程；竞争对比矩阵；单位经济表；36–60 个月财务预测（收入、毛利、EBITDA、净利润、期末现金）；资金用途饼图/表；里程碑时间线；团队介绍；风险矩阵。

**语气与篇幅**：有观点、简洁、数字说话；正文 20–35 页，执行摘要 1–2 页，另配 10–15 页路演 PPT。

**常见被毙原因**：市场规模用自上而下的大数字糊弄；收入曲线是"每年翻倍"没有机制；毛利率高于行业头部却不解释；对竞争对手一笔带过或说"没有竞争对手"；资金用途写"运营资金 80%"；团队页空洞。

**关键指标**：收入 CAGR、毛利率、EBITDA 率转正年份、CAC/LTV、回本周期、月度/年度现金消耗、runway、融资后估值与稀释、投资回报倍数（情景）。

## 2. 银行与贷款机构

**他们怎么读**：信贷审查的核心问题只有一个——**钱怎么还、还不上怎么办**。他们从现金流和偿债能力开始看，然后看借款人资质、担保措施，最后才看行业与市场。增长故事越激进他们越不安。

**评审关注点**：
1. 还款来源：经营现金流覆盖本息的倍数（DSCR，通常要求 ≥ 1.2–1.5）；保守情景下是否仍能覆盖。
2. 借款人资质：成立年限、历史财务报表、纳税与信用记录、股东背景、实缴资本。
3. 用途合规：贷款用途具体、与经营匹配（设备、建设、流动资金各有不同产品）。
4. 担保与风险缓释：抵押物、保证人、应收账款质押、政策性担保。
5. 项目可行性：产品是否有稳定需求、合同或订单支撑、行业周期性。
6. 财务稳健性：资产负债率、流动比率、利息保障倍数、应收账款周转。

**必须有的内容**：贷款申请要素（金额、期限、用途、还款计划、担保）；历史财务摘要（有则必须）；12 个月现金流预测 + 贷款期内年度现金流；DSCR 逐年表；保守情景分析（销量/价格下降时的偿债能力）；担保措施说明；资质与合规文件清单。

**语气与篇幅**：稳健、保守、数据完整、不渲染愿景；预测偏保守，上行情景可以不写。正文 20–30 页，附表要全。

**常见被毙原因**：还款来源依赖"未来融资"或"资产出售"；预测期现金流紧绷、DSCR 刚过 1；用途笼统；没有历史财务或与纳税申报数据不一致；担保措施缺失；对行业下行风险没有压力测试。

**关键指标**：DSCR（最低值与各年）、利息保障倍数、资产负债率、流动比率、速动比率、应收/存货周转天数、最低现金余额、贷款期内累计经营现金流 / 本息总额。

## 3. 政府申报、补贴与园区招商

**他们怎么读**：评审通常按**申报指南的打分表**逐项打分，看的是政策契合度、申报主体资格、投资强度与产出效益、社会效益、实施可行性和资金使用合规。叙事要对齐政策语言，但每一项都要有可核查的指标。

**评审关注点**：
1. 政策契合：项目属于哪项政策/产业目录/重点方向，引用文件名与条款；与地方产业规划的关系。
2. 主体资格与基础：企业资质、过往项目经验、研发或产业化基础、知识产权。
3. 建设内容与投资：建设地点、规模、内容、总投资与分项（土建、设备、研发、流动资金）、资金来源（自筹、申请资金、银行贷款）与配套比例。
4. 技术方案与创新性：技术路线、先进性对比、标准与认证。
5. 经济效益：达产后产值、税收、利润；投资强度（万元/亩）、亩均税收等园区指标。
6. 社会与环境效益：就业人数、带动上下游、乡村振兴/共同富裕/绿色低碳等政策目标的量化贡献；能耗、排放、环评。
7. 实施计划与保障：进度表、组织保障、风险应对、绩效目标（可考核的指标与年份）。
8. 资金使用与管理：预算明细、使用计划、财务管理制度。

**必须有的内容**：政策依据章节；建设内容与投资估算表；资金筹措表；效益分析表（经济、社会、环境各有量化指标）；绩效目标表；进度甘特图；组织与保障措施；风险分析；相关资质与证明材料清单。

**语气与篇幅**：规范、完整、指标化，可适度使用政策表述但每句话要有实质内容；篇幅按指南，通常 30–60 页，附件多。

**常见被毙原因**：与申报方向不匹配；效益指标空泛（"显著提升"没有数字）；总投资与资金来源对不上；配套资金不足；进度不可行；绩效目标无法考核；环评、用地、能评等前置条件缺失。

**关键指标**：总投资、投资强度、达产年产值与税收、新增就业、研发投入占比、专利/标准数量、能耗与排放指标、投资回收期、财务内部收益率（可研口径）、配套资金比例。

## 4. 内部战略、董事会与合作伙伴

**他们怎么读**：决策者要的是"该不该做、要投入什么、不做会怎样、做砸了怎么办"。他们熟悉公司，不需要公司介绍；他们想看备选方案的比较和决策所需的口径。

**评审关注点**：
1. 战略契合：与公司战略、现有能力和资源的关系；为什么由我们做、为什么现在做。
2. 备选方案：至少比较 2–3 个方案（含不做），用同一套指标评价。
3. 资源需求：资金、人员、产能、管理注意力；对现有业务的影响。
4. 财务口径：投资额、NPV、IRR、回收期、对合并报表的影响、敏感性。
5. 实施与治理：里程碑、决策点（go/no-go）、负责人、汇报机制。
6. 风险与退出条件：什么情况下止损。

合作伙伴版本（招商、合资、渠道）额外关注：合作结构、各方投入与分成、排他条款、知识产权归属、退出机制。

**必须有的内容**：决策请求（一句话说明请董事会批准什么）；方案比较表；资源与预算表；财务评价表（NPV/IRR/回收期 + 敏感性）；里程碑与决策点；风险与止损条件；负责人与治理。

**语气与篇幅**：直接、决策导向、结论先行；正文 10–20 页，附录放细节。

**常见被毙原因**：只有一个方案没有比较；低估资源需求与对现有业务的挤占；没有止损条件；财务口径与公司惯用口径不一致；负责人不明确。

**关键指标**：NPV、IRR、回收期、峰值资金占用、对公司 EBITDA/现金的影响、敏感性（关键假设变动 ±20% 的影响）、战略契合度评分。

## 多读者策略

用户经常需要同一个项目给多类读者看。做法：

1. **一份主文档**按主读者的权重写全，所有章节完整。
2. **每类次要读者一份定制执行摘要（1–2 页）**：首段回答该读者的第一个问题，摘要里引用主文档的章节号。
3. **按读者增加附录或专章**：银行版加"偿债能力分析与担保措施"；政府版加"政策依据"和"效益与绩效目标表"；董事会版加"方案比较与决策请求"；投资人版加"融资方案与估值逻辑"。
4. **财务口径统一**：同一个模型、同一套假设，不同读者只是展示不同指标（银行看 DSCR 与保守情景，投资人看增长与回报，政府看效益指标，董事会看 NPV/IRR）。绝不为不同读者做两套数字。
5. **语气分级**：主文档中性专业；执行摘要可按读者调整（投资人版更有观点，银行版更保守，政府版更规范）。

交付时说明哪份给谁看，提醒用户面向外部的版本要脱敏。

## 章节权重速查

| 章节 | 投资人 | 银行 | 政府 | 内部 |
|---|---|---|---|---|
| 执行摘要 | ★★★ | ★★ | ★★ | ★★★ |
| 公司/项目概况 | ★★ | ★★★ | ★★★ | ★ |
| 产品/服务与技术 | ★★★ | ★ | ★★★ | ★★ |
| 市场分析 | ★★★ | ★★ | ★★ | ★★ |
| 竞争分析 | ★★★ | ★ | ★★ | ★★ |
| 商业模式与单位经济 | ★★★ | ★★ | ★ | ★★ |
| 营销与销售 | ★★ | ★ | ★ | ★ |
| 运营计划 / 建设内容 | ★ | ★★ | ★★★ | ★★ |
| 组织与团队 | ★★★ | ★★ | ★★ | ★ |
| 实施计划与里程碑 | ★★ | ★★ | ★★★ | ★★★ |
| 财务计划 | ★★ | ★★★ | ★★ | ★★★ |
| 融资/申请方案 | ★★★ | ★★★ | ★★★ | ★★（决策请求） |
| 风险分析 | ★★ | ★★★ | ★★ | ★★★ |
| 社会与环境效益 | ★ | ★ | ★★★ | ★ |
| 备选方案比较 | — | — | ★ | ★★★ |

★★★ 展开写、放前面；★★ 完整但精炼；★ 一两段或并入其他章节；— 可省略。
